## Product and scientific acceptance, not additional organizer rules

- Claims:45 draft rows,0 verified rows in the inspected dataset. Never convert draft matching into validated safety, a fire probability or certification. Do not report prediction accuracy, time savings or percentage risk reduction without a reproducible evaluation.
- Distinguish measured experimental conditions from requested scenario conditions, including simulated partial-gravity research. Preserve all tested fields, missing versus 0, original notes, accession/row IDs, caveats and review state in UI and standalone Markdown/JSON. There is no universal 0 g/1 g bracket. Any condition-specific estimate requires reviewed compatible endpoints and explicit assumptions. Existing partial-gravity draft rows must not be described as absent.
- CAD is context, not proof of thermal/fire physics. Premade asset provenance and illustrative material mapping must be explicit. Xray reveals only geometry actually included, not fabricated interiors. A2's20minute acquisition timebox may require retaining the clearly labelled illustrative rover.
- Blue-to-red encodes evidence applicability/review gaps, gray unknown, with categorical labels. Blue must never falsely mean scientifically proven safe. Essential draft/simulation/unknown warnings remain visible.
- High-value demonstration: load bundled model+CSV -> select part -> inspect NASA source and tested conditions -> change scenario and see applicability gaps -> pin/compare -> export/reopen the same brief. No terminal, install, login, API key or mandatory backend for this bundled path.
- Minimum-setup UX: one obvious Load demo action, plain names, selected-part emphasis, understandable next step, reset sample, loading/empty/error states, optional ownCSV. Hover explanations also accessible by focus/tap. No setup wizard or duplicated wall of text.
- Screenshot layout: four navigable sections, compact dark top tabs, left BOM/demo sidebar, large central model, concise top summary, right inspector. Desktop and390px mobile must work without page-wide horizontal overflow.
